## Plan before implementing

Optional rule (`rules.optional: [five-line-plan]`): for people who want to approve a short plan before any code is written.

- A plan is five lines: repo, files to touch, new pieces with a one-line justification each, feature-flag entry point or "pure fix, unflagged", what becomes legacy.
- Ask {{person.name}} for "go" on the plan (not on the worker itself) before implementation starts, and show anything the plan cuts in the same message.
