# Vendored Orca plugin typings

`orca-plugin/` is a snapshot of what `orca plugin types .` writes into `.orca/types/` (git-ignored,
generated by the Orca app's CLI). CI has no Orca CLI, so `npm run typecheck` copies this snapshot to
`.orca/types/` when that folder is missing, and the typecheck always runs.

Refresh it after an Orca update (needs the Orca app):

    npm run types        # regenerates .orca/types and copies it here; commit the diff

A local `.orca/types/` (from the app) wins over the snapshot; delete it to check against the snapshot.
