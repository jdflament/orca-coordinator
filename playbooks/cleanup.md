# cleanup

Daily environment cleanup. Goal: close sessions nobody uses and remove Orca worktrees whose work has shipped, so Orca stays readable. Be conservative: when unsure, list it instead of touching it. The zero-model script `{{paths.bin}}/cleanup` does the safe part; you do the judgment part and the report.

Never: `rm -rf`, migration tools, `git push`, `git stash`, deleting a local branch, touching a worktree with uncommitted changes, closing the coordinator terminal (handle in `{{paths.terminalFile}}`) or any terminal that belongs to a live orchestration worker (`{{paths.orca}} orchestration worker-list --json`, states ready/running).

1. Terminals: `{{paths.orca}} terminal list --json`. A terminal is unused when ALL hold: not the coordinator; not a live worker's terminal; no agent is mid-turn (agent idle or a plain shell); last activity older than 6 hours (use the list's timestamps; if absent, `terminal read --screen` and judge from the prompt). Close those with `{{paths.orca}} terminal close --terminal <handle>`. Keep anything that looks like {{person.name}} typing (a prompt with a half-written line) and list it.
2. Worktrees: `{{paths.orca}} worktree list --json`. Only entries under `{{paths.worktreeRoot}}` are candidates (never the repo checkouts under `{{paths.workspace}}`). For each: `git -C <path> status --short` must be empty; find its PR with `gh pr list -R {{github.org}}/<repo> --head <branch> --state all --json number,state`. Remove the worktree when the PR is MERGED or CLOSED, or when no PR exists and the branch's last commit is older than 14 days and identical to its remote. Use `{{paths.orca}} worktree rm --worktree path:<path> --json` (keeps the local branch). Never pass --delete-branch, never --force.
3. Also list, without acting: git worktrees not registered in Orca (`git -C {{paths.workspace}}/<repo> worktree list` vs Orca's list), stale scratchpad worktrees (`git worktree prune --dry-run` per repo), and empty folders under `{{paths.worktreeRoot}}`.
4. Run `{{paths.bin}}/metrics` once at the end.
5. Report: table of closed terminals (title, age), removed worktrees (path, branch, PR state), kept candidates with the reason, and the "list only" items. Nothing else.
